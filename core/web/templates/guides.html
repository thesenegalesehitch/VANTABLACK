Guides d'Installation Multi-OS

Instructions complètes pour macOS, Linux et Windows

Prérequis macOS

✓ Homebrew installé
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
✓ Python 3.11+ via Homebrew
brew install python@3.11
✓ Vérification PEP 668
python3.11 -m pip config list | grep break-system-packages

Installation macOS

1

Cloner le repository

git clone https://github.com/vantablack/core.git
2

Créer l'environnement virtuel

python3.11 -m venv venv
3

Activer et installer les dépendances

source venv/bin/activate && pip install -r requirements.txt
4

Lancer l'application

python -m core.cli.main

Vérification Installation

Version Python
python --version
Doit afficher Python 3.11+
Dépendances
pip list
Vérifier toutes les dépendances
Test API
curl http://localhost:5000/v5/health
Doit retourner status 200

Dépannage macOS

Erreur PEP 668 - --break-system-packages

Solution:

python3.11 -m pip config set global.break-system-packages false
Python version incorrecte

Vérifier le path:

which python3.11
Problèmes de permissions

Réparer les permissions:

sudo chown -R $(whoami) /usr/local/*
